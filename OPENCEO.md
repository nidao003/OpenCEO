# OpenCEO

OpenCEO is an open-source AI operating office for founders and small teams. This repository starts from Leantime v3.9.8 and adds company memory, employee-report intelligence, AI-assisted project maintenance, company state and management-loop workflows.

## V0.1 foundation

- Company Profile / Company Memory
- Word weekly/monthly report ingestion
- Project Alias / Candidate / Human verification
- AI project observations separated from manual truth
- Company State snapshots
- Meeting Decisions / Actions / Risks
- Monthly Draft → Supplement → Final output chain
- WeCom Word-upload entry point
- Weekly/monthly summary, meeting material, PPT-outline and video-narration text outputs

Rendered PPT/video generation is intentionally Phase 2.

See `docs/openceo/ARCHITECTURE.md` and `docs/openceo/DEPLOYMENT.md`.
